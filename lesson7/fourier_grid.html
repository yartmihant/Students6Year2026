Все гармоники по отдельности

Каждая частота показана на своей сетке. Сначала рассмотрите базисные синус и косинус, затем переключитесь на их вклад в выбранную функцию. Точки — значения в узлах; линии помогают увидеть форму между ними.

━ cos(2πkx)┄ sin(2πkx)

Что именно разлагается?

Сетка: xⱼ = j/N, j = 0, …, N−1. Точка x = 1 не дублируется: дискретное преобразование Фурье подразумевает периодическое продолжение. При всех N степенях свободы сумма совпадает с любыми заданными значениями в узлах с точностью округления. Между узлами показан тригонометрический интерполянт, а не единственно возможная исходная функция.

uⱼ = a₀ + Σ[k=1…N/2−1] {aₖ cos(2πkxⱼ) + bₖ sin(2πkxⱼ)} + aₙ cos(πj),   n = N/2

Для 1 ≤ k < N/2: aₖ = (2/N)Σⱼuⱼ cos(2πkj/N), bₖ = (2/N)Σⱼuⱼ sin(2πkj/N). Постоянная a₀ = (1/N)Σⱼuⱼ. На частоте Найквиста aₙ = (1/N)Σⱼuⱼ(−1)ʲ: её синус в узлах равен нулю. Получаются 1 + 2(N/2−1) + 1 = N независимых коэффициентов.

Во время анимации текущая гармоника плавно включается с весом w от 0 до 1. Это способ показать сложение, а не эволюция функции во времени. Около скачков возможны колебания между узлами даже при точном восстановлении всех отсчётов.
