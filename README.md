**Домашнее задание 2.3: Связанные колебания и жёсткость**

Рассмотреть две одинаковые массы, каждая из которых соединена пружиной с неподвижной опорой. Между массами находятся дополнительная пружина и демпфер. Смещения от положения равновесия удовлетворяют уравнениям:

$$
\begin{aligned}
m\ddot x_1&=-k_0x_1-k_c(x_1-x_2)-c(\dot x_1-\dot x_2),\\
m\ddot x_2&=-k_0x_2-k_c(x_2-x_1)-c(\dot x_2-\dot x_1),
\end{aligned}
$$

где $k_0$ — жёсткость пружин, соединяющих массы с опорами, $k_c$ — жёсткость соединительной пружины, $c$ — коэффициент демпфирования.

Исследовать биения, сравнить численные частоты с собственными частотами системы. Повторить расчёт для нескольких шагов.
