# Решения домашних заданий на жёлтый уровень

Выполнены все три задания из корневого README по состоянию на 10 сентября 2026 года.
Каждый самостоятельный notebook включает зелёную основу и весь жёлтый уровень,
пояснения на русском, выполненные ячейки, численные таблицы, графики и анимации.

## Как посмотреть

Откройте [index.html](index.html) в браузере: там три решения и прямые ссылки на восемь анимаций.
HTML и анимации работают локально; сохраняйте структуру папок при переносе.
Формулы в HTML-копиях оставлены в записи LaTeX; в Jupyter они отображаются обычным математическим набором.

| Задание | Jupyter notebook | Просмотр без Jupyter |
|---|---|---|
| 1.1. Маятник | [1.1_pendulum_yellow.ipynb](1.1_pendulum_yellow.ipynb) | [HTML](1.1_pendulum_yellow.html) |
| 1.2. Баллистика | [1.2_ballistics_yellow.ipynb](1.2_ballistics_yellow.ipynb) | [HTML](1.2_ballistics_yellow.html) |
| 1.3. Орбиты | [1.3_orbits_yellow.ipynb](1.3_orbits_yellow.ipynb) | [HTML](1.3_orbits_yellow.html) |

В Jupyter откройте файл, выберите Python 3 и выполните **Restart Kernel and Run All Cells**.
Кнопки под анимациями позволяют воспроизводить, останавливать, повторять и выбирать кадр.
Если просмотрщик блокирует сохранённый JavaScript, выполните ячейки самостоятельно
или используйте локальную HTML-версию. GitHub обычно не воспроизводит встроенные анимации.

В ноутбуках нет скрытых зависимостей от файлов проекта: каждый содержит свои функции
Эйлера, RK4, подготовки графиков и анимаций. Параметры опытов расположены рядом с расчётами.
Папка `animations/` создаётся в текущем рабочем каталоге ядра.

## Повторный запуск

Из этой папки при необходимости установите зависимости и запустите Jupyter:

```powershell
python -m pip install -r requirements.txt
python -m jupyterlab
```

Или пересчитайте все notebooks и обновите HTML без интерфейса Jupyter:

```powershell
python tools/execute_notebooks.py
```

Один файл можно передать аргументом:

```powershell
python tools/execute_notebooks.py 1.2_ballistics_yellow.ipynb
```

`tools/build_notebooks.py` — исходный генератор материалов. Его повторный запуск
**перезаписывает три notebooks и очищает сохранённые результаты**; после ручных изменений
ноутбуков он не нужен. Для обычной работы достаточно самих `.ipynb`.

Проверенное окружение: Python 3.13, NumPy 2.3.5, SciPy 1.16.3, Matplotlib 3.10.7.
FFmpeg и дополнительные виджеты не требуются. Основное время выполнения уходит на
подготовку кадров. В проверенном окружении весь комплект выполняется примерно за две минуты;
время зависит от процессора и скорости файловой системы.

Проверки `assert` сопоставляют результаты с независимыми аналитическими эталонами,
проверяют уменьшение ошибки RK4, сохранение энергии маятника, убывание энергии
при сопротивлении, точность свободного броска, общий орбитальный период и равенство площадей.
Численный период определяется по событию, а не из подставленного аналитического времени.
Интерполяция на частоту кадров применяется только для визуализации.

## Результаты, полезные для обсуждения

- Маятник: при относительной ошибке периода до 1% линейная модель допустима примерно
  до 23°. Для амплитуды 90° ошибка около 15%; уменьшение шага её не устраняет.
- Баллистика при v₀=20 м/с: для k=0, 0.01, 0.03, 0.08 м⁻¹ оптимальные углы
  на сетке 0.05° равны 45°, 43°, 40.40°, 37°. При k=0.03 и броске под 45°
  вершина находится на 55.9% дальности, угол падения около 58.8°.
- Орбиты: при a=1 период равен 2π для всех e. При e=0.8 скорости в перицентре
  и апоцентре отличаются в 9 раз, характерное время у перицентра примерно
  в 15 раз меньше кругового. Равномерная временная сетка должна это разрешать.

## Оценка сложности для преподавателя

Оценки ниже — ориентиры для выполнения с нуля, включая оформление; это не наблюдённые
времена студентов и не время машинного расчёта. Предполагается знакомство с ОДУ и механикой.

| Работа | Python уже знаком | Первый опыт NumPy/Jupyter | Основные трудности |
|---|---|---|---|
| 1.1. Маятник | 6–10 ч | 10–16 ч | Численный период, отделение ошибки модели, три анимации |
| 1.2. Баллистика | 7–12 ч | 12–18 ч | Событие падения, два шага дискретизации, синхронизация запусков |
| 1.3. Орбиты | 9–15 ч | 15–24 ч | Начальные условия эллипса, эталон, перицентр, заметённые секторы |

Научное содержание соответствует продвинутому уровню, но обязательные анимации
занимают заметную часть работы. Для первого семинара все три варианта неравноценны
по трудоёмкости: орбитальный вариант сложнее остальных.

Чтобы оценивать преимущественно численную механику, полезно выдать общий шаблон
`FuncAnimation` с двумя панелями и объяснить уточнение события внутри шага.
Для маятника стоит заранее задать допустимую ошибку периода (здесь выбрано 1%);
для баллистики — точность поиска угла; для орбит — верхний предел e (здесь 0.8).
Иначе студенты могут потратить много времени на разную, неоговорённую точность.

Эллиптический интеграл и решение уравнения Кеплера в этих решениях добавлены как
независимые проверки. Жёлтый уровень можно выполнить проще: измерять период маятника
по сходимости и накладывать параметрическую форму эллипса без точной отметки положения во времени.
